Arboris, un catalogue de skills pour agents IA

Projet personnel · en ligne

Le besoin

Disposer de skills et de slash commands prêts à l’emploi pour son agent IA — Cursor, Claude, Codex ou Copilot — sans rien avoir à configurer. C’est la question à laquelle répond Arboris.

Ce que l’application propose

  • un catalogue filtrable ;
  • une fiche détaillée par skill, avec un prompt à copier ;
  • un parcours « premier pas » selon la stack ;
  • une authentification ;
  • une interface en français et en anglais, avec thème clair ou sombre ;
  • une installation possible par fichier ZIP ou en ligne de commande avec arboris-cli.

Technologies

Application web full-stack à rendu serveur. Stack : TypeScript, React 19, TanStack Start, Prisma, PostgreSQL, Docker, Tailwind CSS, Vitest et Vercel.

  • TypeScript
  • React 19
  • TanStack Start
  • Prisma
  • PostgreSQL
  • Docker
  • Tailwind CSS
